# Connectors - Technical Documentation

Meltano Cloud connectors fall into one of five categories:

- Extractors and Loaders (also know as Taps / Targets) move data from and to sources and destinations respectively.
- Mappers allow you to transform data between extractors and loaders.
- Utilities allow virtually any open source data tool to be integrated with your project.
- Files allow you to easily add new file-based resources to your data project.

Here you will find in-depth documentation for our more popular connectors, including configuration and setup guides. Search or filter below to find the connector you need.
