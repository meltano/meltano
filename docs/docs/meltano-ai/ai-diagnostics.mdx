# AI Diagnostics

When a run or deployment fails, Meltano AI reads the failure and explains what went wrong in plain language, with steps to fix it. You can ask for a diagnosis in the Meltano Cloud app, and it is also included in your failure alert emails, with a next step matched to the failure.

It runs on your own Claude API key, added once in **Settings → Integrations**.

The full guide, including how your data is handled, is in Meltano Cloud: [Diagnose with Meltano AI](/meltano-cloud/diagnose-with-meltano-ai).
