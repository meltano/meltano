# Plugins

Plugins are the building blocks of a workspace: sources (extractors), warehouses (loaders), transforms such as dbt, mappers, utilities and file bundles. Open **Plugins** in the sidebar to see the plugins installed in the workspace.

You don't need to install a source or warehouse before using it: [New Ingestion](/meltano-cloud/ingestion#add-an-ingestion) and [Add a warehouse](/meltano-cloud/warehouses#add-a-warehouse) install what they need, and so does [New Workflow](/meltano-cloud/workflows#add-a-workflow) for a component from the catalog.

---

## The list

Search the list, or filter it by type. Each plugin shows its name and description, its type, its version, and who supports it:

- **Meltano Supported**: a plugin Meltano maintains.
- **Community Supported**: a plugin maintained by its community.
- **Custom Plugin**: a plugin you added from your own definition.

When a newer version of a plugin is available, its row has an **Update** button. Updating replaces the plugin's definition with the latest version; your configuration is kept.

Click a plugin to open its own page, with its **Name**, **Variant**, **Version**, **Package**, **Namespace**, **Capabilities**, **Repository**, and **View docs**.

---

## Add an official plugin

You need to be an administrator of the workspace.

1. Click **+ Plugin**. The **Add Plugin** drawer asks where the plugin comes from.
2. Choose **Official Plugin**.
3. Search the catalog, and filter it by type if you like. **Show More** lists more results; plugins already in the workspace are marked **Installed**.
4. Pick the plugin and click **Install**.

---

## Add a custom plugin

If a plugin isn't in the catalog, add it from a Meltano `discovery.yml` file that defines it. The file can define several plugins, such as an extractor and its dbt transforms.

1. Click **+ Plugin** and choose **Custom Plugin**.
2. **Choose File** to pick your `discovery.yml`, or paste its YAML into the **discovery.yml** box.
3. Click **Add**. The new plugins appear in the list, marked **Custom Plugin**. **Reset** clears the box.

See [Ingestion](/meltano-cloud/ingestion#add-a-custom-source) for an example, and the [plugin definition reference](/concepts/plugins#custom-plugins) for the format.

---

## Delete a plugin

Open the plugin's **⋮** menu (on its row or its page) and choose **Delete**. Deleting a plugin also deletes the ingestions and workflows that use it, so the confirmation says so first.

**Delete** is greyed out when another plugin requires this one, or when you are not an administrator.
