# Log Routing and Monitoring

Meltano Cloud keeps run logs for 7 days (see [Run History, Logs and Watching](/meltano-cloud/run-history)). To keep them longer, search them, or alert on them, send them to Datadog.

---

## Send logs to Datadog

You need a Datadog account and API key, and to be an administrator of the workspace.

1. Open **Settings → Integrations**.
2. Under **Datadog**, click **Add Credential**.
3. Fill in:
   - **API key**: your Datadog API key.
   - **Datadog site**: the site your account is on, so logs reach the right data centre.
   - **Service name (optional)**: the name the Meltano logs arrive under in Datadog. Use it to filter them and build dashboards.
4. The credential is tested. Click **Save** to keep it.

The logs of your ingestions and workflows are then sent to Datadog.

---

## Manage the credential

From the Datadog credential's **⋮** menu:

- **Pause** stops sending logs without removing the credential; the credential shows **Paused**. **Resume** starts again.
- **Remove** deletes the credential, for example to rotate the API key or change site. Logs stop being sent to Datadog; Meltano's own log store is unaffected.

When a run's log is older than 7 days, its log in Meltano Cloud says it may still be in Datadog.
